# Data

The datasets are included directly in this folder — no download needed.

## Files

| File | Rows | Source |
|---|---|---|
| `Books.csv` | 271K | Book-Crossing dataset, compiled by Cai-Nicolas Ziegler |
| `Ratings.csv` | 1.1M | Book-Crossing dataset |
| `Users.csv` | 279K | Book-Crossing dataset |
| `books_1.Best_Books_Ever.csv` | 52K | Best Books Ever dataset, scraped from Goodreads by Lorena Casanova Lozano & Sergio Costa Planells (CC BY-NC 4.0) |

## Sources

- Book-Crossing dataset: https://www.kaggle.com/datasets/arashnic/book-recommendation-dataset
- Best Books Ever dataset: https://github.com/scostap/goodreads_bbe_dataset

Credit to the original compilers/scrapers above — this repo just uses their data for the recommendation models in `notebooks/`.
